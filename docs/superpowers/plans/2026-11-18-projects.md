# Projects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Projects tab (Project → Heading → Task → Subtask, plus Supplies & tools) to HouseKeeper.
**Architecture:** One `projects/<id>` doc per project with nested arrays; People list in `meta/people`. UI in index.html
(new module, own `data-pact`/`data-pform` listeners to avoid touching existing handlers); server adds project task due dates
to `collect_items` and a `sensor.family_tracker_shopping` sensor.
**Tech Stack:** vanilla JS single page, Python http.server + SQLite store.
**Spec:** docs/superpowers/specs/2026-11-18-projects-design.md

## Global Constraints
- Keep existing sensor IDs/events/backup format. Project due-soon window: 14 days. Version 1.5.0 + tag + release.
