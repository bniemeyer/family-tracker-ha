# Niemeyer Family Apps for Home Assistant

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fbniemeyer%2Ffamily-tracker-ha)

## Apps

- **Niemeyer Family Tracker** — garage, parts & tools, home maintenance and seasonal checklists, with reminders and sensors. See [family_tracker/DOCS.md](family_tracker/DOCS.md).

## Install

Settings → Apps → Install app → ⋮ → Repositories → add `https://github.com/bniemeyer/family-tracker-ha`, then install **Niemeyer Family Tracker**.
